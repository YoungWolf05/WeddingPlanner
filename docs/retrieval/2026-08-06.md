## Method

Metrics are produced by deterministic, LLM-free functions in `src/core/retrieval-eval.ts` over DOCUMENT-LEVEL relevance (the ranked chunk list is reduced to distinct source documents). Relevance is referenced in `evals/retrieval.jsonl` by stable `source_uri` (the 7c app-owned document identity), so the dataset does not go stale when chunking is tuned. The same pure functions grade this live run and the offline test suite.
